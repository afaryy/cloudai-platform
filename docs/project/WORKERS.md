# Worker Roles

These roles describe Codex-based development responsibilities for future work.

## Architecture Worker

- Maintains architecture docs and decision records.
- Keeps AWS-first and multi-cloud-ready positioning consistent.

## Platform Worker

- Adds Terraform and cloud provider scaffolding.
- Must keep mock mode as the default unless a task explicitly permits deployment.

## Application Worker

- Builds mock gateway, API, frontend, and worker examples.
- Uses synthetic data only.

## Security Worker

- Reviews public-safety boundaries, CI checks, secret scanning, and least-privilege patterns.

## Documentation Worker

- Keeps docs concise, portfolio-safe, and aligned with roadmap phases.
