## Mission

Build a Cloud & AI platform engineering portfolio project that demonstrates an AWS-first, multi-cloud-ready Enterprise AI Control Plane reference implementation.

## Why This Exists

The project is positioned as an AWS-first, multi-cloud-ready learning and reference implementation using synthetic examples and public cloud service patterns.

## Scope

- P0 Foundation documentation and project controls.
- Track A AWS GenAI Platform Starter as the first implementation direction.
- Track B EKS release engineering placeholders.
- Track C AI-assisted DevSecOps pattern placeholders.
- Track D AI traffic gateway and Kubernetes-native agent runtime research notes.
- Track E LLMOps / GPU sandbox as a future stretch track.
- Mock mode and synthetic examples by default.

## Non-Goals

- No product-readiness claim.
- No real cloud deployment in P0.
- No platform-readiness claim.
- No real credentials or live cloud deployment in P0.
- No full working transcripts in git.

## Success Criteria

- Phase and track status are traceable in `docs/project/status.json`.
- Human-readable summaries are kept aligned with the structured status file.
- Project scope remains clear and reviewable.
- Each phase produces small, portfolio-friendly increments.
