# Assessment Rubric

<!-- TODO: Future automation can calculate rubric scores from docs/project/status.json readiness fields. -->

Rate each area from `0` to `3`.

| Area | 0 | 1 | 2 | 3 |
| --- | --- | --- | --- | --- |
| Phase completion | No phase defined | Phase named | Phase has deliverables | Phase has verified deliverables |
| Track completion | No tracks | Tracks named | Tracks mapped to phases | Tracks have measurable outcomes |
| Delivery gaps | Unknown | Listed informally | Categorized | Owned and tracked |
| Security and governance gaps | Unknown | Described | Mapped to controls | Tested or evidenced |
| FinOps and observability gaps | Unknown | Described | Mapped to signals | Runtime evidence exists |
| Documentation completeness | Missing | Partial | Broad foundation | Complete for current phase |
| Demo readiness | Missing | Script outline | Mock demo | Verified demo |
| Public safety compliance | Missing | Informal | Documented | Explicit and checked |
