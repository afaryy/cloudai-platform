# Responsible AI Checklist

Use this checklist before moving a demo pattern toward a real implementation.

- Use synthetic examples in public artifacts.
- Define intended users and use cases.
- Document excluded and unsupported uses.
- Apply model and data access controls.
- Review prompt, response, and tool-use safety risks.
- Capture audit events for policy decisions.
- Track cost and usage signals.
- Provide a human escalation path for sensitive outcomes.
- Validate provider terms and regional requirements before deployment.
